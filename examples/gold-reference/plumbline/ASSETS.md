# Plumbline — asset provenance

**There are none.**

This prototype uses no photographs, no illustrations, no icon set and no downloaded files of
any kind. Everything visible on the site is one of three things:

1. Type, set in system font stacks (`Inter` if the reader has it, then the platform UI face;
   `ui-monospace` and its fallbacks for anything the product is depicted as having written).
   No web font is requested, so the site makes no network call to a third party.
2. A diagram drawn in HTML and CSS from the data in `src/data/product.ts` — the plan, the
   lock bars, the check register, the grant list.
3. One inline SVG, the plumb-line mark in the header and the favicon, drawn here.

That is a design decision before it is a licensing one. A staff engineer does not buy
database tooling from a photograph, and a category whose every competitor illustrates itself
with abstract network graphics is a category where showing the actual output is the only
distinctive move available. It happens to also mean there is nothing on this site that could
be mistaken for a licensed or business-owned asset, because there is no asset.

The company, its customers, its people, its metrics, its testimonials and the migration plan
are all invented. The domain is `.invalid` and can never resolve.
