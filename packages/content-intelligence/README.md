# @app-builder/content-intelligence

Deterministic Phase 3 intake tooling.

It converts mixed real-world sources into normalized source records and a trusted knowledge pack before any generative build work starts.

Supported deterministic extractors:
- text / Markdown / JSON
- HTML and existing-site pages
- CSV
- PDF
- DOCX
- XLSX
- common image formats via Sharp

The package is factory tooling only. Generated applications do not depend on it.
