# Recipes

Recipes are optional, independently installable capabilities for generated projects.

Planned examples: auth, profiles, organisations, admin, billing, email, notifications, uploads, search, audit log, analytics, observability, SEO, lead generation, PWA, AI, background jobs, integrations and feedback.

A recipe must eventually declare its files, dependencies, schema/migrations, environment requirements, tests, install/remove operations and compatibility version. Do not add placeholder code for every recipe before it is actually implemented.
